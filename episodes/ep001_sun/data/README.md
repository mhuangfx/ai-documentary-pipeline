# Sunspot data (not included)

`cardlib.py` reads the monthly and smoothed sunspot series `SN_m_tot_V2.0.txt` and
`SN_ms_tot_V2.0.txt` from SILSO, Royal Observatory of Belgium (https://www.sidc.be/SILSO/).
They are licensed CC BY-NC 4.0, so they are not redistributed here. Download them into this folder.
